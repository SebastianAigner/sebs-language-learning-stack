# Audio Files

Place your audio files in this directory.

## Audio Files

- `correct.mp3` - Plays when the user's answer exactly matches the correct answer
- `wrong.mp3` - Plays when the user's answer is incorrect

## Recommendations

- Keep audio files short (< 1 second)
- Use MP3 format for broad browser compatibility
- Keep file sizes small for fast loading
- Volume is set to 50% by default in the code

## Finding Sound Effects

You can find free sound effects at:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

Search for terms like:
- For correct: "correct", "success", "ding", "chime", "win"
- For wrong: "wrong", "error", "buzz", "fail", "incorrect"
